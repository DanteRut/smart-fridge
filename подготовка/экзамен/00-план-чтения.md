# План чтения на сегодня (пересдача)

**Формат:** вопрос → развёрнутая теория → каркас ответа (формулируешь сам, вставляя ключевые фразы) → вероятные уточняющие преподавателя → ход от твоего проекта.

**🔄 Весь цикл по шагам** — у каждого В есть блок «как это крутится в программе»: конкретная история по шагам с реальными JSON/HTTP/кодом из проекта. Если тема не заходит — читай сначала цикл (он про понимание), потом теорию (она про точные формулировки).

**Обозначения:** ⭐ — вопрос был на прошлом экзамене (приоритет 1, читается первым). ➕ — новая вариация той же темы (приоритет 2).

## Порядок (если времени мало)

1. Все ⭐ вопросы (В1, В3, В4, В5, В6, В7, В10, В11, В12, В13, В14, В16, В17, В18, В19) — ~4.5 ч. Они повторятся с высокой вероятностью.
2. Перерыв, еда.
3. ➕ вопросы (В2, В8, В9, В15, В20) — быстрые, закрывают смежные углы тех же тем.
4. Перед сном: пробеги только по «Каркасам ответов» всех 20 — освежи скелеты.

## Правило ответа на экзамене (четыре шага, всегда)

1. **Термин/название** механизма — показывает, что ты в контексте.
2. **Механика** своими словами — как это работает внутри.
3. **Компромисс/цена** — назови сам, не дожидаясь вопроса «а чем это плохо?».
4. **Пример из проекта** — «в моём smart-fridge это вот так, и вот известный компромисс».

Даже если забыл конкретику — рассуждай вслух от идеи: «ломающие изменения только через аддитивность», «опасен тихий сбой», «абстракция переносит сложность, а не убирает» — и выйдешь на ответ.
