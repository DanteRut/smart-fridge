# Anki: импорт и план на вт–чт

## Импорт (5 минут, один раз)

1. Открой Anki → **Файл → Импорт** → выбери `01-факты-и-термины.txt`.
2. В диалоге импорта проверь:
   - **Тип заметок:** Basic (Front/Back)
   - **Поля разделены:** Tab (символ табуляции — подставится сам)
   - ☐ **Разрешить HTML в полях** — НЕ включай: файлы — чистый текст без разметки
   - **Колода:** создай новую — `СОП::01-Факты` (можно ввести имя прямо в диалоге)
   - Колонок в файле **ровно две**: вопрос → ответ (тегов нет — приложение их не поддерживает)
3. Повтори для `02-сценарии-что-сломается.txt` → колода `СОП::02-Сценарии`,
   `03-аналитика-на-подумать.txt` → `СОП::03-Аналитика`,
   `04-практика-напиши.txt` → `СОП::04-Практика`.

В тексте карточек нет двойных кавычек (заменены на одинарные) и HTML-тегов —
импортёр не будет их «склеивать» или резать.

**Маркер технологии.** Почти каждый вопрос начинается с метки области:
`[REST]`, `[HTTP]`, `[HATEOAS]`, `[PATCH]`, `[Валидация]`, `[GraphQL]`,
`[Protobuf]`, `[gRPC]`, `[RabbitMQ]`, `[События]`, `[Sealed]`, `[Контракт]`,
`[BFF]`, `[Проект]`, `[сквозное]` (верно для любой технологии). В колоде
04 — `НАПИШИ [REST]: …`, `НАПИШИ [gRPC]: …` и т.д. Если метки нет, технология
названа прямо в вопросе (например, «Перечислите 7 принципов REST»).

иди читай её цикл по шагам), код-рецепты: `экзамен/06`.

## План: вторник → пятница

**Вторник (сегодня, вечер):** импорт + колода 01 целиком (~73 новых — Anki сам
разложит повторения). Правило: **отвечай вслух** до переворота, не «узнаю».

**Среда:** колода 02 (новые) + повторение хвостов 01. Вечером — колода 04 первый
проход: пиши от руки на бумаге, потом сверяй с back.

**Четверг:** колода 03 (новые) + все должники (жёлтые/красные). Вечером — полный
прогон: Anki показывает только карточки «на повторении», плюс перепиши REST-контракт
на «Авторе» по памяти за 7 минут (тренажёр из 06-файла).

**Пятница (утро):** только проваленные карточки + Скелет и Готовые фразы из
шпаргалки-watch. Ничего нового не учить.

## Настройки Anki (быстро)

- Колода `СОП` → параметры: **новых в день 60–80** (иначе не успеем до пятницы),
  шаги изучения стандартные (1м 10м).
- Учить в режиме «вперёд-назад» не включать — трата времени.
- Смешать колоды при повторении: у колоды СОП включить «v3 scheduler» и учить
  общим потоком — мозг тренируется переключаться между областями, как на экзамене.

## Как отвечать, чтобы связи крепли

1. Прочитал front → **закрой глаза, сформулируй вслух** (проговаривание = укрепление).
2. Перевернул → сверил не «угадал/не угадал», а **«сказал ли я ключевые слова»**.
3. Оценка «Трудно» → карточка вернётся сегодня; не срезай — честность сейчас =
   уверенность в пятницу.
4. Сценарные карточки (колода 02) проговаривай в формате экзамена:
   «термин → что произойдёт по шагам → как чинить → у нас в проекте…».
